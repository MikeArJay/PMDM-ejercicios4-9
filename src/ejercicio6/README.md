Escribe un programa que solicite al usuario dos palabras y utilizando una función retorne verdadero o falso según sean o no anagramas. La salida del programa debe ser un mensaje indicando si las palabras introducidas por el usuario son o no un anagrama.

Un anagrama consiste en formar una palabra reordenando TODAS las letras de otra palabra inicial. Por ejemplo: amor y roma.

    NO hace falta comprobar que ambas palabras existan.
    Dos palabras exactamente iguales no son anagrama.
